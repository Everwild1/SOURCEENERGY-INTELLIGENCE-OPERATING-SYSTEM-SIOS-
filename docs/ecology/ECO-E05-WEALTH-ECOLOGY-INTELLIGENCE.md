# ECO-E05 — Wealth Ecology Intelligence Layer

Parent: #229  
Issue: #238  
Depends on: ECO-E01–E04

## Purpose
ECO-E05 converts governed Ecology projections into explainable Wealth Ecology intelligence. It is an analytical layer, not a new system of record or financial authority.

## Intelligence families
- **Value throughput / circulation:** aggregates referenced value flows without creating balances or transaction records.
- **Impact posture:** preserves estimate / observed / verified distinctions and source lineage.
- **Regenerative ratio:** compares proposed/realized reinvestment with realized value using an explicit denominator policy.
- **Authority concentration:** HHI-style dependency measure over value by source authority.
- **Domain diversity:** participation breadth across authoritative bounded domains.
- **Evidence coverage:** proportion of inputs carrying explicit confidence/evidence posture.
- **Lifecycle velocity / bottlenecks:** elapsed-time and stalled-stage indicators over ECO-E02 journey edges.

## Explainability contract
Every intelligence result must expose the metric name, deterministic value, measurement posture, source references and formula/method explanation. Future persistence under `ecology` must retain methodology/version and correction lineage rather than overwriting historical calculations.

## Evidence and verification
Ecology must never promote an estimate to observed or verified merely because multiple inputs agree. `verified` is retained only when all contributing inputs carry verified posture and an explicit source/external verification authority. Mixed verified/observed inputs derive an observed result; any estimated contributor yields an estimated result.

## Authority invariants
An intelligence result never confers settlement finality, ledger balance, ownership, IP rights, treasury authority, capital approval, compliance approval, fiduciary authority or logistics execution status. WIM, HEI, CRUDS, GSC/RGL, Capitalization, Source Coin, SETC and regulated/external authorities remain authoritative for their source records.

## ECO-E04 compatibility
Inputs are projections from `ecology.value_flow_references`, `ecology.impact_lineage`, `ecology.journey_edges`, `ecology.object_references` and related source-domain references. ECO-E05 does not require a database migration for its first contract gate.

## ECO-E06 handoff
ECO-E06 may consume ECO-E05 outputs to create regenerative allocation/reinvestment **proposals**. Intelligence scores alone cannot authorize, execute or settle an allocation.
